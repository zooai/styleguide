# styleguide

**Org:** zooai · **Origin:** https://github.com/zooai/styleguide.git

The delta for Zoo. Every actual convention lives in `hanzoai/styleguide`, which
is public and MIT OR Apache-2.0; this repo holds only what is different here — the org, the
registry, the domains, where proposals and papers go.

Adding a rule that is true of every org is a bug: it belongs upstream, where all
three orgs read it. Adding a rule true of one Zoo repo is also a bug: it belongs
in that repo's own LLM.md. What lands here is true of Zoo and only Zoo.
